# Onboarding

## 1. Clone the repo
- Navigate to where you want to work on the project.
```
git clone https://github.com/SS26-Capstone/rare-species.git
cd rare-species
```

## 2. Install dependencies
```
npm install
```

## 3. Install VS Code extensions

- Prettier - Code formatter
- ESLint

Then in VS Code settings, enable Format on Save.

## 4. Verify it works
```
npm run dev
```
Open http://localhost:3000.

## 5. Never work on main or dev directly
```
git checkout -b feature/your-feature-name
```
